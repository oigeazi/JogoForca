# Jogo da Forca — Pedido Interativo

Um jogo da forca interativo criado em React para transformar um pedido especial em uma experiência personalizada, romântica e memorável.

O projeto foi desenvolvido como uma aplicação web com fases progressivas, animações, efeitos sonoros, músicas, interação com o usuário e uma tela final comemorativa com fotos. A ideia foi usar tecnologia não apenas como ferramenta funcional, mas como parte da narrativa de um momento importante.

## Sobre o projeto

Este jogo foi criado para um pedido de namoro. A experiência é dividida em cinco fases:

1. A pessoa começa adivinhando uma frase em formato de elogio.
2. Depois, precisa descobrir a frase principal: “Quer namorar comigo?”.
3. Em seguida, escolhe entre “Sim” ou “Não”.
4. Após a resposta positiva, uma música romântica toca enquanto acontece o momento do anel.
5. Por fim, o jogo exibe uma comemoração com efeitos visuais e fotos do casal.

O objetivo foi criar uma experiência simples de jogar, mas emocionalmente envolvente, combinando lógica de jogo, design visual, áudio, surpresa e narrativa.

## Como rodar localmente

Clone o repositório:

```bash
git clone https://github.com/oigeazi/JogoForca.git
```

Acesse a pasta do projeto:

```bash
cd JogoForca
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```
